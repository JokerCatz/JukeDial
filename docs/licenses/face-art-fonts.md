# Fonts rendered into the designed faces (the card plug-in _player/faces.zip)

tools/gen/make_faces.py draws the fixed bilingual labels of the designed clock / stopwatch / countdown / pomodoro faces with these fonts;
only the rendered greyscale pixels are in faces.zip, no font file or glyph outline is shipped:

- Noto Serif CJK TC Bold, Noto Sans CJK TC Bold (Google / Adobe, SIL Open Font License 1.1; see noto-sans-cjk-OFL.txt for the notice and tools/OFL-1.1.txt for the text)
- IBM Plex Sans Condensed Bold (IBM, SIL Open Font License 1.1; tools/OFL-1.1.txt)

The art itself (frames, stripes, honeycombs, seven-segment digits) is original, drawn by the script.
