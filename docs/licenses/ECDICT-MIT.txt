ECDICT - English to Chinese dictionary database
Source: https://github.com/skywind3000/ECDICT (commit 39cfb9672c0906b63569e0453c2e6abfb9ab182a, fetched 2026-11-11)
Licence: MIT (the repository's LICENSE file, copied verbatim below; the GitHub API reports spdx_id MIT).
Used by: tools/gen/make_vocab.py builds the 單字 vocab decks (glyph packs) from ecdict.csv (word, translation, pos, tag,
frq, bnc). The 66 MB CSV stays in .local/ecdict/ (git-ignored, never committed); the decks (derived data) go to the
TF card; the 100-word sample is app/main/assets/vocab/sample.zip (in the firmware).

Other parts of a deck:
- Chinese text converted from simplified to traditional characters with OpenCC (https://github.com/BYVoid/OpenCC,
  Apache-2.0), run on the PC only; nothing of OpenCC is in the firmware.
- Glyph bitmaps rendered from Noto Sans CJK TC (SIL OFL 1.1, the same licence text as docs/licenses/noto-emoji-OFL.txt).
- tools/gen/vocab/roots.tsv (roots, prefixes, suffixes, short meanings, example words): written for this project.
