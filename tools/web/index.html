怎麼連線

  1. 用 USB 線把本機接到這台電腦。
  2. 插頭要插「設定面」：本機螢幕若顯示「USB 隨身碟」或問你要不要切換成隨身碟，表示插在隨身碟那面，請把 USB-C 翻面再插。
  3. 按右上角「連線」，選 USB JTAG/serial debug unit（Linux 上是 ttyACM0）。清單只會列出本機這類裝置。
需要電腦版 Chrome 或 Edge。找電台和試聽不用連線也能用。

日出日落
尚未設定位置：本機的時鐘頁和日光錶面不顯示日出日落（月相、節氣只需要時區）
本機沒有設定位置時，時鐘頁和「日光」錶面不會顯示日出日落（本機上也沒有別處可以設定）；月相和節氣只需要時區，不受影響。要顯示的話，位置只能在這裡設定。步驟：
1. 按下面的「取得位置」，瀏覽器會問你是否允許這個頁面取得位置，請選允許。
2. 只有緯度和經度會被存下來，而且四捨五入到 0.01 度（約一公里）；存在本機的記憶卡，不會上傳到網路，也不含你的 Wi-Fi 資料。
3. 之後隨時可以按「清除位置」刪掉，日出日落就不再顯示。

更新韌體

    
把新版韌體寫進本機。需要電腦版 Chrome 或 Edge。流程：選板子 → 選你下載的韌體檔 → 連線並檢查 → 備份（建議）→ 寫入。寫入期間不要拔線，也不要關掉這個分頁。這個頁面本身不放韌體。

    
連不上時：按住本機的 BOOT 針孔再插上 USB 線（進下載模式，需要你在場），然後再按「連線並檢查」。圓形板的針孔在 USB-C 旁邊；FakePod 沒有針孔：兩個鍵同時按住再開機（或插上 USB）。
